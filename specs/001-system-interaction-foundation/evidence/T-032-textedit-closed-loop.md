# T-032 TextEdit 完整闭环验证证据

## 任务边界

- 任务：T-032 [Verification] 验证 TextEdit 完整闭环。
- 依赖：T-031 GREEN（见 `evidence/T-031-end-to-end-green.md`）。
- 要求记录：选区前后字节不变、预览前零写入、确认后只替换选区、恢复原文、关闭恢复状态后的标准 Undo 行为。

## 验证环境

- Mac：MacBook Pro（Mac15,3，Apple M3，8 GB）
- macOS：26.5.2（25F84）
- TextEdit：1.20
- 应用构建：Debug、universal，代码状态 `d95228e`（首轮）/ `c3c1fa2`（复核轮）
- 输入内容：仅 `SYNTHETIC-001` 标记的合成文字；无真实用户内容

## 已验证结果（2026-07-27 至 2026-07-28，人工操作）

1. 选区替换闭环：在 TextEdit 中选中合成文字，⌃⌥⌘P 唤出预览，确认替换后
   选区被替换为 `【系统交互验证】\n` + 原文；面板进入可恢复状态，
   "恢复原文"成功还原（操作者反馈："textedit已成立"）。
2. 权限缺失路径：重建二进制触发 TCC 重新授权时，面板展示权限说明与
   "重新检测"，重新授权后闭环恢复可用（AC-003 观察）。
3. 期间修复并已提交的阻塞项（详见 `d95228e` 提交说明）：预览自激活误判
   staleTarget、非激活面板按钮无响应、写入结果回读确认。
4. 标准 Undo（FR-012 兼容性观察）：确认替换、关闭面板后在 TextEdit 按
   ⌘Z，文档恢复为替换前内容（操作者反馈 2026-07-28："在 TextEdit 里按
   ⌘Z，就变回去了"）。替换后整行内容为 `【系统交互验证】\n` + 原选区
   文字，与 FR-006 定义一致。

5. 选区前后文字逐字节不变（AC-005）：使用"前缀/选区/后缀"三段式合成
   文本（`SYNTHETIC-001前缀 / SYNTHETIC-001选区 / SYNTHETIC-001后缀`），
   只选中中间段并确认替换，前缀与后缀逐字符保持不变，仅中间段被替换
   （操作者反馈 2026-07-28："都成立"）。
6. 预览前零写入（FR-007）：预览面板出现时核对文档内容与触发前完全一致，
   随后取消，无任何修改（操作者反馈 2026-07-28："都成立"）。

## 结论

T-032 要求记录的全部行为（选区前后字节不变、预览前零写入、确认后只
替换选区、恢复原文、标准 Undo）均已在真实 TextEdit 环境人工验证通过。
